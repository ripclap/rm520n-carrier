# Assembly preview

Open `assembly-preview.kicad_pcb` in the KiCad 10 3D viewer. This presentation
board adds an installed modem and illustrative component bodies to the Rev A
layout. It is for viewing and does not replace `../rev-a/carrier.kicad_pcb`,
the manufacturing source. Use primary component drawings and the fabrication
requirements for dimensional and seating acceptance.
